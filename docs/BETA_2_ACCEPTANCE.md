# MSG 1.0.0-beta.2 修正版验收（2026-10-09）

状态：已恢复缓存移动，完成本地 release 构建、App 签名完整性和隔离独立自检。经用户同意，已备份本机已安装的 0.3.7，并替换为 1.0.0-beta.2；安装目录与本版构建逐文件比对、版本和签名检查通过，进程已启动。尚未公开发布或移动真实缓存，GUI 仍待本版确认。beta.1 只读方案已撤回；旧版 CI、DMG 校验与 GUI 结果不能替代本版验证。

## 功能与边界

- 10 个默认缓存类别可按时间扫描、逐文件选择、全选/全不选、二次确认后移到废纸篓；默认不选。
- 相关应用仍运行时需额外确认，可以选择先退出或强制移动已选白名单文件。
- 强制确认不能绕过 Library/Caches 子目录边界、禁止整目录、受保护索引文件、符号链接和身份/大小/日期变化检查。
- 取消文件选择会清空本轮确认状态；取消最终确认不调用移动服务。
- 缓存和安装包都只调用系统 Trash，不永久删除用户文件、不自动清空废纸篓、不卸载应用。
- 数值版本 1.0.0，完整版本 1.0.0-beta.2，构建 23；仅 arm64，临时本地签名。

## 仍待验证与已知风险

1. 本版最终包 GUI：类别与文件全选/全不选、取消、正常与强制确认、系统 Trash 与恢复。
2. 本版最终 DMG 构建与下载校验；当前本地仅 App 构建，不沿用 beta.1 的 DMG。
3. 另一台 M 系列 Mac、最低系统、首次下载与系统授权、升级、通知及登录启动。
4. 各缓存类别的真实应用可用性、离线及重建影响未充分验证。风险等级与用户确认不是安全保证，移到废纸篓仍可能干扰应用，恢复也不保证撤销已发生的影响。
5. 最后身份/大小/日期检查和系统 Trash 非原子；不要同时修改或替换所选文件，未声称彻底消除此竞争窗口。
6. 本版未经 Developer ID 签名或 Apple 公证，其他设备可能阻止首次打开。

公开发布仍需用户最后确认。可以先验证安装和查看，不要求试删真实文件。稳定 1.0.0 仍需补齐验收。
