# beta.3 更新提醒验收记录

日期：2026-10-10。版本：1.0.0-beta.3，当前构建号 25。**已公开发布为 Pre-release**；线上 beta.2 及其附件没有被替换。构建 24 的试用包已备份，用户退出 MSG 后，本机“应用程序”中的 beta.2 已备份并更新为构建 25。

## 本次范围

新增手动检查更新、可选每日查询、正式版/测试版频道、发布说明及官方发布页入口。自动查询默认关闭；只读取公开版本信息，不自动下载或安装。原有缓存和下载安装包的逐文件选择、确认及移到废纸篓功能没有被禁用。

## 已实际完成

- 使用本机 Command Line Tools 和 macOS 26.5 SDK 完成开发构建及发布应用打包。
- `MacSpaceGuardSelfTest --test-updates` 的隔离模拟测试通过：版本排序（含 beta.2/beta.10）、频道、草稿/安装包/链接过滤、默认不自动联网、本地偏好及查询间隔、分页、HTTP 错误、无效数据、离线及超时。
- 完整 `MacSpaceGuardSelfTest` 自检通过，包括既有缓存与安装包的临时测试夹具；没有清理用户真实缓存，也没有清空真实废纸篓。
- 实际 GitHub API 查询成功。当时公开版本为 beta.2，当前本地 beta.3 因此得到“没有更高且可下载的公开版本”，符合预期。曾出现 HTTP 403，后续重试返回 200；403 会作为无法查询处理，不会报成已是最新版。
- 打包应用的版本资源为 beta.3 / 24，临时本地签名完整性校验通过；ZIP 内包含应用。**这不等于 Developer ID 签名、Apple 公证或 Apple 安全认可。**
- 本地差异格式检查通过。
- 用户截图已确认构建 24 菜单包含“检查更新”“更新设置”，且手动查询窗口正确显示 beta.3、正式版及测试版频道以及“未发现可下载的新版本”。这是这两处界面的人工证据，不覆盖全部 GUI 路径。
- 构建 25 增加运行实例检测和进程锁，在创建菜单栏图标、通知和扫描任务前检查。独立进程自检通过：第二进程拒绝、正常退出后重启、进程终止后重启、锁文件符号链接拒绝、创建失败报告。完整自检回归也通过。未用终止用户应用来测试此逻辑。
- 构建 25 本机安装后版本/构建资源以及临时签名完整性检查通过。构建 24 签名结果仍作为旧记录保留。
- 本机已将六份构建/试用/旧备份/缓存验收应用移到专用 `.noindex` 归档目录，并改为 `.bundle-backup`，每份另有经过 ZIP 完整性检查的压缩备份。检查“应用程序”、个人应用目录、下载目录和 Codex 项目目录后，仅发现 `/Applications/MacSpaceGuard.app` 这一份对应 `.app`。
- 用户随后提供了重新搜索 `msg` 的截图，结果只剩一个 MacSpaceGuard；本机应用搜索界面已人工确认。此证据不代表其他设备的搜索索引或旧副本也已处理。
- 2026-10-10 再次执行完整隔离自检以及构建 25 的发布应用打包，均成功；未修改已安装应用，也未操作真实缓存或废纸篓。生成 DMG 仍返回“设备未配置”，`diskutil` 同时无法使用 DiskManagement framework，转为尝试仓库 CI 构建。

- 本机只有 Command Line Tools，没有可用 XCTest；本机 `swift test` 因无法导入 XCTest 未运行成功。随后仓库 CI 的完整 XCTest、隔离自检和打包已实际通过，见下方最终包记录；本机环境限制仍存在。
- 原生界面自动访问仍超时。构建 24 的菜单和无新版窗口已有用户截图确认；构建 25 的菜单以及最终 CI 包启动、手动查询已有人工截图确认。防重复启动的 GUI 弹窗、新版通知点击、频道切换和开关交互仍待实测，不能将构建成功等同于全部 GUI 验收。
- 尝试仅刷新/注销 MSG 对应路径的系统应用登记失败，返回 -10822/-10814；未重建或清空全系统索引。随后用户截图已确认本机应用搜索只剩一项，不能将此推广为所有设备的验证结果。
- 防重复启动的原子进程锁只约束采用同一锁的新版本；启动时额外检测已运行旧版，但无法改变旧版代码、阻止旧版之后自行启动。不要从备份解压后并行运行旧版。
- 没有实际等待 24 小时验证后台定时提醒；间隔与去重逻辑已隔离测试，但系统通知投递仍待实测。
- 本轮真实网络没有更高版本，发现新版的路径由模拟数据验证；未发布假版本来触发提示。
- 本机创建 DMG 时系统返回“设备未配置”，不能依靠本机环境生成 DMG。随后已取得仓库 CI 生成的真正 DMG，见下方记录；本地试用 ZIP 没有被重命名或冒充 DMG。
- 另一台 Apple Silicon Mac、最低 macOS 13、真实应用缓存影响、离线与重建影响仍未完成实测。编译最低版本不是兼容性保证。
- 既有构建警告仍存在，包括 SDK 搜索路径及缓存扫描的并发捕获警告，未在本次更新提醒功能中宣称已消除。
