# MSG 安装说明

[English](INSTALL.en.md)

当前构建为 **1.0.0-beta.1 公开测试版**。另一台 Mac、首次下载打开的系统授权体验和最低系统兼容性尚待验证，不是稳定版。

## 适用电脑

仅面向 Apple Silicon（M 系列）Mac，界面为中文，不提供 Intel 版本。编译最低版本为 macOS 13，但没有验证整个 macOS 13+ 范围。本轮本机测试系统和结果见[验收记录](BETA_1_ACCEPTANCE.md)。

## 下载与安装

1. 打开[官方仓库 Releases](https://github.com/Dimoo-rich/MacSpaceGuard/releases)，找到标为 Pre-release 的 1.0.0-beta.1。若没有 DMG，表示尚未发布。
2. 下载 `MSG-1.0.0-beta.1-AppleSilicon.dmg` 和 `SHA256.txt`。Source code 的 zip/tar.gz 是源码，不是安装包。
3. 双击 DMG，将 MacSpaceGuard 拖进“应用程序”。若已有旧版，先退出旧版；替换前保留旧版备份。
4. 从“应用程序”打开。入口在屏幕顶部菜单栏，不会在程序坞常驻。
5. 自行决定是否允许通知、登录启动。自动检查默认每 6 小时一次，仅统计，不移动文件。

## 首次打开的系统提示

这是临时本地签名（ad-hoc）包，没有 Developer ID 签名或 Apple 公证。临时签名校验成功不代表 Apple 已审核，macOS 可能阻止首次打开。

只有确认来自官方仓库、未遭篡改且理解未经公证风险，才按[Apple 官方说明](https://support.apple.com/zh-cn/102445)决定是否打开：尝试打开后，在“系统设置 → 隐私与安全性”查看是否有“仍要打开”。设备管理策略和系统版本会影响此选项，不能保证每台 Mac 都能授权。

不要关闭系统安全保护。若提示恶意软件、文件损坏或没有授权入口，停止安装并反馈，不用终端命令强行解除。

## 第一次试用

先查看菜单栏状态、打开缓存只读页面和安装包页面。不必清理任何真实文件也能提交安装反馈。

此测试版所有缓存仅查看，不提供移动或强制移动。安装包页面支持逐项选择和二次确认后移到废纸篓；不要同时修改、替换或下载所选文件。识别结果不验证安装包来源。

## 废纸篓与恢复

仅确认后的下载安装包会移到废纸篓。**要腾出空间，需要自行检查并清空废纸篓，MSG 不会代为清空。** 不确定的文件先保留。

清空前可在访达的废纸篓选中文件，使用“放回原处”或手动恢复到原路径。恢复不保证撤销已发生的影响；清空后无法再通过废纸篓恢复。
