# MSG 安装说明

[English](INSTALL.en.md)

当前 0.3.7 是预览版，真实废纸篓与另一台 Mac 的发布验收尚未完成。目前仓库提供源码，尚未提供通过发布验收的公开安装包。以下步骤用于准备后续下载版。

## 适用电脑

目标为 Apple Silicon（M 系列）Mac；构建最低系统版本为 macOS 13，实际支持范围须待兼容性验收后确定。不提供 Intel 版本。应用界面目前为中文。

## 下载与安装

1. 打开 [MSG 官方仓库的 Releases](https://github.com/Dimoo-rich/MacSpaceGuard/releases)。如果没有安装包，表示尚未发布。
2. 在所选版本的附件中下载 `MacSpaceGuard.dmg`。`Source code (zip)` 和 `Source code (tar.gz)` 是源码，不是安装包。
3. 双击 DMG，将 MacSpaceGuard 拖进“应用程序”。
4. 从“应用程序”打开。MSG 的入口在屏幕顶部菜单栏，不会在程序坞常驻。
5. 按自己的需要决定是否允许通知，以及是否开启登录时启动。自动检查默认每 6 小时一次，可以调整；自动检查不移动文件。

## 首次打开的系统提示

零预算版本使用临时本地签名（ad-hoc），没有 Developer ID 开发者身份和 Apple 公证，macOS 可能阻止首次打开。下载包会标明此限制。

只有确认文件来自上述官方仓库、未遭篡改，并理解未经公证的风险后，才按 [Apple 官方说明](https://support.apple.com/zh-cn/102445)自行决定是否打开：尝试打开后，前往“系统设置 → 隐私与安全性”，查看是否提供“仍要打开”，再确认。系统版本和设备管理策略可能影响可用选项，不能保证每台 Mac 都能授权。

不要关闭整个系统的安全保护。若提示发现恶意软件或文件损坏，或没有可用的授权入口，停止安装并到仓库反馈；不要用终端命令强行解除。

## 整理与恢复

MSG 只处理你选择并确认的文件，缓存和安装包都移到废纸篓。**要真正腾出空间，需要你自行检查并清空废纸篓；MSG 不会代为清空。**

不确定的文件先保留，相关应用建议先退出。需要恢复时，先退出相关应用，再在访达的废纸篓查看文件，使用系统提供的“放回”或手动恢复到原路径。恢复不保证能撤销应用已经发生的异常。清空后无法再从废纸篓恢复。
