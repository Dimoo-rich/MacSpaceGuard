# MSG 隐私说明

公开下载版仍为 1.0.0-beta.2。下述更新查询功能从本地准备中的 1.0.0-beta.3 起提供，尚未公开发布。

MSG 在本机运行，没有账户、广告或分析 SDK。当前代码没有主动上传扫描结果、文件名或使用情况的功能。macOS 自身的通知、公证和系统服务行为不属于 MSG 的数据上传功能。

## 会读取什么

- 系统提供的内存、交换空间和磁盘余量，用于菜单栏显示和本地提醒。
- 白名单缓存目录中的路径、文件类型、大小和修改时间，用于筛选待审核文件；不会扫描整个资源库，也不会读取聊天记录、浏览器密码或文稿内容。
- 用户选择的文件夹第一层 `.dmg`、`.pkg` 安装包，以及包内用于识别应用的名称、标识和版本。检查 DMG 时会临时只读挂载，检查 PKG 时会临时展开；不会运行安装程序。
- 本机常见应用目录及系统应用登记中的应用名称、标识和版本，用于对照安装包。对照结果不是安装来源证明。

## 会保存什么

自动检查间隔保存在本机系统偏好设置中。扫描结果只在应用运行期间使用；MSG 不建立扫描历史数据库。登录时启动开关由 macOS 管理。若允许通知，提醒由 macOS 在本机显示。

更新频道、每日更新检查开关、上次查询时间和上次提醒的版本号也保存在本机偏好设置中；不记录用户行为或建立远程用户档案。

## 更新查询何时联网（beta.3 起）

扫描、统计和移到废纸篓仍在本机进行。更新查询是独立的可选联网功能，不应将“本地处理”理解为应用永远不会联网。

- 首次使用“每日检查更新”默认关闭，启动应用不会因为更新功能自动连接网络。
- 点击“检查更新”会向 `api.github.com` 的本项目公开 Releases 接口发送只读请求；开启每日检查后，在应用运行且距上次请求至少 24 小时时查询。失败也遵循此间隔，避免自动反复请求。
- 查询使用固定服务地址，不携带 GitHub 账号凭据、Cookie、文件、文件名、扫描结果或使用统计，也不在请求头发送当前应用版本。版本比较在本机进行。
- GitHub 及网络服务提供方能获得普通连接信息，例如 IP 地址和请求头。MSG 无法替第三方承诺不保留服务日志。
- “前往下载”会打开浏览器访问本项目的 GitHub 发布页，浏览器自身的登录、Cookie 和隐私设置另行生效。MSG 不自动下载、安装或执行新版，也不改动 macOS 安全设置。
- 每日检查可在“更新设置”关闭；手动点击检查仍会发起一次查询。网络不可用不影响本地扫描和移动文件。

流程与频道见 [更新说明](UPDATES.md)。

## 何时移动文件

自动检查和“立即检查”只统计，不移动文件。缓存和下载的安装包只有在用户选择并再次确认后才移到废纸篓；运行中应用的缓存还需额外确认。强制移动不能绕过禁止范围或文件检查。MSG 不会自动清空废纸篓。移到废纸篓后仍占用磁盘空间，需用户自行检查并清空才会释放；清空后不能再从废纸篓恢复。

反馈是用户手动填写或发送，不会自动生成、导出或上传诊断报告。

当前处理范围与风险见 [清理范围](CLEANUP_SCOPE.md) 和 [安全审计](SAFETY_AUDIT.md)。功能与隐私问题可通过 [项目 Issues](https://github.com/Dimoo-rich/MacSpaceGuard/issues)反馈；不要在公开反馈中提交私人文件名、账号凭据或扫描清单中的敏感内容。
